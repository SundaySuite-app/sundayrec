Feil varsles på selve maskinen. Under Varsler ser du om systemet viser SundayRecs varsler, med «Send testvarsel» og «Åpne innstillinger». På Windows blir kortet gult hvis varsler er slått av. Stillhet, manglende lyd og en lydkilde som faller ut varsles nå også når vinduet ikke er foran, og vekking som ikke kan settes opp sier fra.

Eksporten har fått «Innhold»: tittel, taler og beskrivelse følger med i fila. Etterpå kan appen åpne siden dere legger ut på, med teksten klar til å kopieres. Appen laster ikke opp noe selv.

E-postvarsler er fjernet. Hadde du dem slått på, viser Opptak-siden én gang en beskjed om endringen.
